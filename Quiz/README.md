# 🧠 Design and Analysis of Algorithms Quiz App

A simple interactive quiz application based on **Design and Analysis of Algorithms (DAA)** concepts.

## ✨ Features

- Multiple-choice DAA questions
- 15-second timer for each question
- Automatic score calculation
- Next Question button
- Final score display
- Simple and attractive interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📚 Topics Covered

- Dynamic Programming
- Sorting Algorithms
- Graph Algorithms
- Divide and Conquer
- Binary Search

## 🚀 How to Run

1. Download or clone the repository.
2. Open the `Quiz` folder.
3. Open `index.html` in a web browser.
4. Start the quiz.
