# 🏋️ Fitness for Everyone

A simple and responsive **fitness blog front-end website** created using HTML5 and CSS3. The project is designed to provide a clean and attractive homepage with fitness-related content and information.

## 🌟 Features

- 🏠 Attractive fitness homepage
- 💪 Fitness and workout content
- 🥗 Healthy nutrition information
- 🧘 Daily fitness tips
- 🌿 Healthy lifestyle section
- 📰 Fitness article cards
- 📱 Responsive and clean user interface
- 🖼️ Fitness-related images

## 🛠️ Technologies Used

- HTML5
- CSS3
