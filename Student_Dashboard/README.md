# 📊 Student Dashboard

A simple and responsive Student Dashboard webpage created using **HTML5 and CSS3**.

## ✨ Features

- Student dashboard interface
- Clean and simple design
- Responsive layout
- Student information display
- Easy-to-use navigation

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📁 Project Structure

```text
Student_Dashboard/
├── Output/
│   ├── student_dashboard_output1.png
│   └── student_dashboard_output2.png
├── README.md
├── index.html
└── style.css
```

## 🚀 How to Run

1. Download or clone the repository.
2. Open the `Student_Dashboard` folder.
3. Open `index.html` in a web browser.
4. The Student Dashboard webpage will be displayed.

## 📸 Output

Screenshots of the Student Dashboard are available in the `Output` folder.
